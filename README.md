# مسیر یاب تهران

اپلیکیشن ناوبری فارسی اندروید با نقشه تهران، مسیریابی هوشمند، دستورات صوتی و اتصال به هوش مصنوعی **Gemini**.

## امکانات

- 🗺️ **نقشه تهران** — کامل و رایگان (OpenStreetMap / OSM)
- 🧭 **مسیریابی واقعی** — محاسبه مسیر با OSRM روی نقشه تهران
- 🤖 **اتصال به Gemini AI** — با **API Key شخصی خودتان**، به صورت گفتاری یا متنی بگویید کجا می‌خواهید بروید؛ مسیر «دستورات فارسی» به شما می‌دهد: از کدام خیابان بروید، چقدر راه هست، از کجا بپیچید
  - نمونه: «برو میدان آزادی بدون ترافیک» → مسیر + فاصله + زمان + مسیر خیابان‌ها
  - اتصال Gemini اختیاری است؛ بدون آن هم مسیریابی کامل کار می‌کند
- 📍 **موقعیت زنده GPS** — نمایش نقطه مبدا روی نقشه با آیکون متحرک و جهت‌نما
- 📏 **فاصله تا مقصد** — به‌صورت زنده از موقعیت فعلی تا هدف (کیلومتر/متر)
- 🔊 **راهنمای ناوبری صوتی فارسی** — «۵۰۰ متر دیگر به چپ بپیچید», «به مقصد رسیدید»
- 🛣️ **ناوبری قدم‌به‌قدم** — نوبت‌به‌نوبت با تصویر مانور، بمانید/بپیچید به چپ/راست، خط مستقیم
- 🔁 **محاسبه مسیر مجدد** — اگر از مسیر خارج شدید، مسیر جدید تا مقصد محاسبه می‌شود
- 🔦 **حالت شب** — برای رانندگی در شب
- ⭐ **مقاصد ذخیره‌شده** — نشان‌کردن مکان‌های پرمراجعه
- 💬 **رابط کاملاً فارسی و راست‌به‌چپ**

## راه‌اندازی

1. APK را از [بخش Releases](https://github.com/3krbkbkrbrbg/tehran-nav-android/releases) دانلود و نصب کنید
2. مجوزهای موقعیت مکانی را بدهید
3. (اختیاری) در تنظیمات، **API Key Gemini** خود را وارد کنید:
   - از [aistudio.google.com/apikey](https://aistudio.google.com/apikey) بگیرید
   - در اپ: تنظیمات ⚙️ → «اتصال به هوش مصنوعی» → کلید را ثبت کنید
4. جستجو کنید یا از AI بپرسید: «به فرودگاه مهرآباد برو»
5. **شروع ناوبری** را بزنید و برانید — دستورات صوتی فارسی شما را راهنمایی می‌کند
